# функция для перевода из 10 в другую систему счисления

Функция:

```python
def func_transfer(x, s):
    if x == 0:
        return '0'
    r = ''
    while x > 0:
        r = str(x % s) + r
        x = x // s
    return r
```

Пример использования функции:

```python
# пример
print(func_transfer(10, 2)) # 1010
print(func_transfer(100, 5)) # 400

r = func_transfer(10, 3) # Теперь r - это строка в которой лежит '12'

```

## **Описание**

x - число которое хотим перевести, **именно число, а не строка!**

s - система счисления, в которую хотим перевести

### Как это работает?

Разберем на примере:

Представим что мы хотим перевести 10 из **десятичной** в **двоичную** систему счисления**.**

Но и алгоритм описанный выше делает то же самое !!

Давайте наглядно:

| Шаг алгоритма | r | x |
| --- | --- | --- |
| 1 | 0 | 5 |
