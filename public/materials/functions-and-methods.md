# Функции

### 🔹 `print()`

**Что делает:**

Функция `print()` выводит информацию на экран — текст, числа, переменные, списки и всё, что угодно.

**Синтаксис:**

```python
print(что_нужно_вывести)
```

Можно передавать сразу несколько объектов:

```python
print("Привет", name, age)
```

**Простой пример:**

```python
print("Hello, world!")
```

**Что выведет:**

```
Hello, world!
```

**Возможные ошибки:**

- Если забыть закрыть кавычки:

    ```python
    print("Hello)  # ❌ ошибка
    ```

- Если забыть скобки в Python 3:

    ```python
    print "Hello"  # ❌ ошибка
    ```


---

### 🔹 `input()`

**Что делает:**

Функция `input()` считывает ввод с клавиатуры. Всё, что вводит пользователь, сохраняется в виде строки (`str`).

**Синтаксис:**

```python
input()
```

или с подсказкой:

```python
input("Введите что-нибудь: ")
```

**Простой пример:**

```python
name = input("Как тебя зовут? ")
print("Привет,", name)
```

**Что вернёт / как работает:**

Если пользователь введёт `Егор`, то программа выведет `Привет, Егор`.

**Важно:**

`input()` всегда возвращает строку. Если нужно получить число, используй `int()` или `float()`:

```python
age = int(input("Сколько тебе лет? "))
print(age + 1)
```

**Где используется:**

Эта функция используется почти во всех задачах, где нужно прочитать данные от пользователя — будь то имя, числа или целые строки.

**Возможные ошибки:**

- Если сразу применить `int(input())`, а пользователь введёт не число — будет ошибка.
- Все введённые данные — строки. Даже если ты ввёл `123`, это будет `'123'`.

---

### 🔹 `int()`

**Что делает:**

Преобразует значение в целое число. Обычно используется для преобразования строки (например, с числом) в тип `int`.

**Синтаксис:**

```python
int(значение)
```

**Простой пример:**

```python
age = int("18")
print(age + 1)  # 19
```

**Что вернёт / как работает:**

Если ты передаёшь строку `'18'`, то `int('18')` вернёт число `18`.

**Важно:**

- Нельзя преобразовать строку, в которой нет цифр: `int("abc")` вызовет ошибку.
- Можно округлить в меньшую сторону число с плавающей точкой:

```python
int(4.9)  # даст 4
```

**Где используется:**

При работе с пользовательским вводом, при чтении данных из файла, когда нужно работать с числами.

**Возможные ошибки:**

- `int("12abc")` — ошибка, потому что строка содержит не только цифры.
- `int("")` — ошибка, пустая строка.

### 🔹 `str()`

**Что делает:**

Преобразует значение в строку. Удобно для склеивания текста и чисел.

**Синтаксис:**

```python
str(значение)
```

**Простой пример:**

```python
age = 20
text = "Мне " + str(age) + " лет"
print(text)  # Мне 20 лет
```

**Что вернёт / как работает:**

`str(123)` вернёт `'123'`, `str(True)` — `'True'`.

**Где используется:**

Очень много будем использовать практически во всех заданиях из-за срезов

Когда нужно превратить любое значение (число, логическое значение, список и т.п.) в строку, например для вывода.

**Возможные ошибки:**

Ошибок почти не вызывает — работает с любыми типами данных.

**Синтаксис:**

```python
float(значение)
```

**Что вернёт / как работает:**

- `float(4)` → `4.0`

**Где используется:**

Когда нужно работать с дробными числами или переводить строки в дробные значения.

**Возможные ошибки:**

- `float("abc")` — ошибка.
- `float("12.3.4")` — ошибка.

### 🔹 `range()`

**Что делает:**

Создаёт последовательность чисел — от одного до другого с шагом. Удобно для циклов.

**Синтаксис:**

```python
range(конец)
range(начало, конец)
range(начало, конец, шаг)
```

**Простой пример:**

```python
for i in range(3):
    print(i)
# Выведет: 0 1 2
```

**Что вернёт / как работает:**

- `range(5)` — числа от 0 до 4 (НЕ включая 5).
- `range(2, 6)` — 2, 3, 4, 5
- `range(10, 2, -2)` — 10, 8, 6, 4

**Где используется:**

Циклы `for`, генерация списков, индексы при переборе элементов.

**Возможные ошибки:**

- `range(5, 1)` ничего не вернёт (нужен шаг, если хочешь идти в обратную сторону).
- `range("a")` — ошибка, нужна только цифра.

### 🔹 `all()`

**Что делает:**

Функция `all()` проверяет, что **все элементы в списке— "истинные"** (то есть не равны `False`, `0`, `''`, `None` и т.п.).

**Синтаксис:**

```python
all(список)
```

**Простой пример:**

```python
print(all([True, 1, 'text']))
```

**Что вернёт / как работает:**

Вернёт `True`, потому что все элементы "истинные".

**Важно:**

- Если хотя бы один элемент "ложный" — результат будет `False`.
- Если коллекция пустая (`[]`) — возвращает `True` (потому что нет ни одного ложного элемента).

**Где используется:**

- Проверка условий для всех элементов списка.
- В логических задачах.

**Возможные ошибки:**

Обычно нет — функция безопасная. Но если передать нечто, что нельзя итерировать (`all(5)`), будет ошибка типа.

# Методы

### 🔹 `.count()`

**Что делает:**

Метод `count()` **считает, сколько раз элемент встречается в строке или списке**.

**Синтаксис:**

```python
строка_или_список.count(элемент)
```

**Простой пример:**

```python
text = 'hello world'
print(text.count('l'))
```

**Что вернёт / как работает:**

Вернёт `3`, потому что буква `'l'` встречается в строке три раза.

**Важно:**

- Работает и со строками, и со списками.
- Регистр важен: `'bbbA'.count('a')` вернёт `0`.
- В списке считает по значениям (например, сколько раз встречается `5`).

**Где используется:**

- Подсчёт символов, слов, чисел.
- Проверка количества вхождений перед заменой, удалением, фильтрацией.

**Возможные ошибки:**

Если применить к чему-то, где метода `.count()` нет — будет ошибка (например, к числу: `5.count(5)` вызовет `AttributeError`).

---

### 🔹 `.replace()`

**Что делает:**

Метод `replace()` **заменяет одну подстроку на другую** в строке.

**Синтаксис:**

```python
строка.replace(что_меняем, на_что_меняем)

```

**Простой пример:**

```python
text = 'hello world'
print(text.replace('l', '_'))
```

**Что вернёт / как работает:**

`he__o wor_d` — все буквы `'l'` заменились на `'_'`.

**Важно:**

- Метод не меняет оригинальную строку — возвращает новую.
- Можно указать третий аргумент: сколько замен делать.

```python
text.replace('l', '_', 1)  # заменит только первую 'l'
```

**Где используется:**

- Очистка текста.
- Замена символов, форматов, шаблонов.

**Возможные ошибки:**

Если использовать не по строке (например, к списку) — ошибка `AttributeError`.

---

### 🔹 `.append()`

**Что делает:**

Метод `append()` **добавляет элемент в конец списка**.

**Синтаксис:**

```python
список.append(элемент)
```

**Простой пример:**

```python
nums = [1, 2]
nums.append(3)
print(nums)
```

**Что вернёт / как работает:**

`[1, 2, 3]` — число 3 добавилось в конец списка.

**Важно:**

- Меняет сам список.
- Добавляет один элемент (не расширяет список).

```python
nums.append([4, 5])  # добавит вложенный список
# [1, 2, 3, [4, 5]]
```

**Где используется:**

- Построение списка по ходу работы программы.
- Сбор данных в цикле.

**Возможные ошибки:**

Метод есть только у списков. У строк — нет.

### 🔹 `.join()`

**Что делает:**

Метод `join()` **соединяет элементы списка в строку через указанный разделитель**.

**Синтаксис:**

```python
'разделитель'.join(список_строк)
```

**Простой пример:**

```python
words = ['a', 'b', 'c']
print('-'.join(words))
```

**Что вернёт / как работает:**

`a-b-c` — элементы соединены через `-`.

**Важно:**

- Работает только со строками.
- Все элементы в списке должны быть строками.

**Где используется:**

- Форматирование текста.
- Сбор строки из кусочков (например, по словам, буквам).

**Возможные ошибки:**

Если в списке есть нестроковой элемент — `TypeError`.

---

### 🔹 `.split()`

**Что делает:**

Метод `split()` **разбивает строку на список по разделителю**.

**Синтаксис:**

```python
строка.split(разделитель)
```

**Простой пример:**

```python
text = 'a,b,c'
print(text.split(','))
```

**Что вернёт / как работает:**

`['a', 'b', 'c']` — строка разбита по запятой.

**Важно:**

- По умолчанию делит по пробелам.
- Если разделителя в строке нет — вернётся список с одной строкой.

**Где используется:**

- Разделение данных (например, из файла или input).

**Возможные ошибки:**

Метод есть только у строк.

---

### 🔹 `.strip()`

**Что делает:**

Метод `strip()` **удаляет пробелы и другие лишние символы с начала и конца строки**.

**Синтаксис:**

```python
строка.strip()
```

**Простой пример:**

```python
text = '  hello  '
print(text.strip())
```

**Что вернёт / как работает:**

`hello` — убраны пробелы с краёв.

**Важно:**

- Не трогает символы внутри строки.
- Можно указать, какие символы убирать:

```python
'--text--'.strip('-')  # вернёт 'text'

```

**Где используется:**

- Очистка данных из `input()`, из файлов и др.
- Подготовка строк перед обработкой.
